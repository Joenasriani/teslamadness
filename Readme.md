# Cybertruck Madness '98

**Game lineage:** Cybertruck Madness '98  
**Status:** current browser racing game in this repository  
**Play:** https://joenasriani.github.io/teslamadness/  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Cybertruck Madness '98 is a retro browser racing game with off road physics and a Cybertruck inspired vehicle.

## Lineage

The repository name `teslamadness` and the earlier label **Tesla Madness** are historical development names for this repository. The current default branch identifies the game as **Cybertruck Madness 1998**.

For search and catalog purposes, treat **Cybertruck Madness '98** as the current canonical game identity for this repository rather than counting Tesla Madness as a second current game.

This is an independent project and is not affiliated with or endorsed by Tesla.

Existing branches and historical files are retained as development history.
